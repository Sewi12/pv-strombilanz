# PV-Strombilanz v4.2.3

Monatliche Stromkosten werden nicht mehr manuell eingegeben, sondern automatisch geschätzt:
- Arbeitspreis brutto: 14,90 ct/kWh
- Grundpreis brutto: 4,62 €/Monat
- Vorläufiger Ansatz für Netzgebühren und Abgaben: aus der bekannten Jahresabrechnung abgeleitet (ca. 10,70 ct/kWh)

Wichtig: Das ist eine Schätzung, keine tatsächliche Monatsrechnung. Netzentgelte, Abgaben und Tarifbestandteile können sich ändern. Sobald die Jahresabrechnung vorliegt, sollten die Schätzungen damit abgeglichen werden.
